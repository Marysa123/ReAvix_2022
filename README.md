# Проект: ReAvix

Автоматизированная система мониторинга учебных и воспитательных процессов в образовательных организациях.

---

### 💡 Цель проекта

Целью разработанной информационной системы "ReAvix" является **автоматизация мониторинга учебных и воспитательных процессов в техникуме** посредством создания удобного и эффективного программного обеспечения.

---

### ⚙️ Задачи и функционал программного обеспечения

Программное обеспечение "ReAvix" было создано для решения следующих ключевых задач:

1.  **Функция отображения посещаемости студентов**:
    * Программа сохраняет информацию о каждом студенте, зарегистрированном в группе.
    * Автоматически записывает посещаемость студентов в специальную таблицу данных.
    * Пользователь может генерировать отчеты, отображающие количество пропущенных занятий по группе.
2.  **Хранение информации о студентах и классных руководителях**:
    * Программа хранит данные о каждом зарегистрированном студенте (имя, фамилия, контактная информация).
    * Информация о классных руководителях также хранится в базе данных.
3.  **Хранение информации об успеваемости студентов**:
    * Программное обеспечение хранит данные о каждом ученике в группе.
    * Включает информацию о курсе, на котором студент зарегистрирован, и оценки, полученные за каждый экзамен и предмет.
4.  **Изменение и удаление всей информации**:
    * Пользователь имеет возможность изменять или удалять любую информацию, хранящуюся в базе данных.
    * Включает данные о студентах, их успеваемости, а также информацию о посещаемости.
5.  **Функция вывода отчетов**:
    * Программное обеспечение позволяет генерировать разнообразные отчеты по запросу пользователя.
    * Включает отчеты о посещаемости группы, оценки студентов и другую релевантную информацию.
6.  **Подсчет статистических данных об успеваемости студентов**:
    * Система может проводить анализ данных.
    * Выдавать статистические отчеты, описывающие средний балл успеваемости группы, оценки в сравнении с другими группами на курсе и т.д.
7.  **Удобное представление информации**:
    * Все данные хранятся в таблицах для легкого доступа.
    * Отображаются в удобном графическом пользовательском интерфейсе (GUI).
8.  **Защита персональной информации**:
    * Механизмы программного обеспечения (например, защита на основе пароля) обеспечивают безопасность данных.
    * Предотвращают несанкционированный доступ.

### 🛠️ Ключевые технологии

* **Язык программирования**: C#
* **Фреймворк**: WPF (Windows Presentation Foundation)
* **Базы данных**: SQL Server, MSSQL
* **Инструменты разработки**: Visual Studio
* **Система контроля версий**: Git
